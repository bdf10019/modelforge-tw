## 3. 不列入 MVP 收尾的項目

以下不是做不到，而是本次不再要求；不因未完成而阻止 MVP 結案：

- 重跑完整 Base／prompt-only／fine-tuned 實驗矩陣、補 bootstrap 信賴區間。
- 新一輪訓練、重訓 v5、建立新模型候選，或為舊產物補簽新版訓練血緣。
- 擴大 challenge、增加新來源資料、近重複研究或繼續調整外部專用 prompt。
- 新增 Ollama、vLLM、SGLang、TensorRT-LLM 或其他推論引擎。
- 多模型並排即時執行、線上 canary、企業 IAM、集中稽核平台等新功能。
- 安裝 Docker／WSL／Kubernetes、實際叢集部署、雲端資源與 production 壓測。
- 新網站、簡報、影片、公開發布或遠端 Git 推送；現有文件與展示頁足以作本輪交付。

已知限制繼續保留在文件中：資料是合成內容；早期 Base／prompt-only 對照只有 14 筆；
跨來源泛化仍有缺口；歷史訓練與 registry 保留原始 schema；容器只有靜態檢查。
**清楚揭露限制即可，不把解決所有限制當成結案條件。**
